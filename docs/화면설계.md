# User Screen Design

- 임시 서비스명 : 섭명뭐(서비스명 뭐하지)
- 문서 버전 : V5
- 갱신일자 : 2026-11-24

Django 티켓 데스크 실행 후 화면별 링크를 열 수 있다. 화면 번호는 기존 설계 식별자를 유지한다.

[별도 실행 시안 시작](../src/pages/design-preview/01-LoginPage/01-LoginPage.html) · [설정 시안 바로 열기](../src/pages/design-preview/07-SettingsPage/07-SettingsPage.html)

화면 간 설정·권한 변경을 확인하려면 저장소 루트에서 `python3 -m http.server 8080 --directory src/pages/design-preview`로 시안 폴더를 열고, 브라우저에서 `http://localhost:8080/07-SettingsPage/07-SettingsPage.html`에 접속한다. 시안은 예시 데이터와 브라우저 저장소를 사용한다.


## 레이아웃 양식

- 업무 홈부터 공통 레이아웃을 사용한다. 화면은 상단 고정 바, 좌측 고정 패널, 본문으로 구성한다.
- 상단 고정 바에 로고·서비스명, 알림, 내 계정, 로그아웃 버튼을 표시한다. 오른쪽의 ‘로그아웃’을 누르면 **01-01 로그인**으로 돌아간다.
- 좌측 고정 패널은 업무 홈, 티켓 목록, 받은 요청, 팔로업, 분석 대시보드, 설정 순으로 배치한다. ‘설정’을 누르면 개인 설정, 업무 관리, 인사 관리가 펼쳐진다. 허용된 하위 메뉴와 현재 화면을 표시한다.


## 01. 로그인 (Task1)

[로그인 시안 열기](../src/pages/01-LoginPage/01-LoginPage.html)

### 01-01 로그인

- 사원은 회사 이메일과 비밀번호를 입력해 로그인한다.
- 회사 이메일 형식이 올바르지 않으면 이메일 입력란 아래에 안내한다.
- 회사 이메일을 비워 둔 채 로그인하면 이메일 입력란 아래에 ‘회사 이메일을 입력해 주세요.’를 표시한다.
- 회사 이메일 형식이 올바르고 비밀번호를 비워 둔 채 로그인하면 비밀번호 입력란 아래에 ‘비밀번호를 입력해 주세요.’를 표시한다.
- 비밀번호는 기본적으로 가린다. ‘표시’를 누르면 확인할 수 있고, ‘숨기기’를 누르면 다시 가린다.
- ‘비밀번호를 잊으셨나요?’를 누르면 **01-02 비밀번호 분실 안내**를 띄운다.
- 관리자가 비밀번호를 초기화한 사원은 전달받은 비밀번호로 로그인한다.
- 일반 로그인에 성공하면 **02-01 업무 홈**으로 이동한다.
- 시연 기간에는 로그인 화면 오른쪽 아래의 ‘업무 홈 시안 보기(임시)’로 02-01 업무 홈을 열 수 있다. 시연용 계정을 부여한 뒤 이 링크를 삭제한다.

### 01-02 비밀번호 분실 안내

- 로그인 화면에 어두운 배경을 덮고, 중앙에 ‘비밀번호 분실 안내’ 대화상자를 띄운다.
- 사원에게 회사 이메일과 함께 사내 관리자에게 비밀번호 초기화를 요청하도록 안내한다.
- 관리자가 초기화한 뒤 전달한 비밀번호로 로그인하도록 안내한다.
- ‘확인’을 누르면 안내창을 닫고 로그인 화면으로 돌아간다.

### 01-03 로그인 요청 중

- 로그인 요청을 처리하는 동안 버튼에 ‘로그인 중…’을 표시한다.
- 요청이 끝날 때까지 로그인 버튼을 비활성화해 중복 요청을 막는다.

### 01-04 로그인 실패

- 회사 이메일 또는 비밀번호가 올바르지 않으면 **두 입력란 모두**에 빨간 테두리를 표시한다.
- 입력란 근처에 ‘이메일 또는 비밀번호를 확인해 주세요.’를 표시한다.
- 사원은 입력값을 확인하거나 수정한 뒤 로그인 버튼으로 다시 시도할 수 있다.

#### 임시 규칙

- HTML 시안은 로그인 화면의 ‘업무 홈 시안 보기(임시)’로 열 수 있다. 카드 배치 저장은 같은 브라우저에서 확인할 수 있다.

## 02. 업무 홈(Task 범위 밖)

[업무 홈 열기](../src/pages/02-WorkHomePage/02-WorkHomePage.html) · [화면 설정 열기](../src/pages/design-preview/07-SettingsPage/07-SettingsPage.html?view=display&from=home)

### 02-01 업무 홈

- 일반 로그인에 성공하면 개인 업무 홈으로 이동한다.
- 본문 카드의 기본 순서는 **내게 할당된 티켓 → 받은 요청 → 내 실적**이다.
- 오늘 배정된 티켓과 이전에 배정됐지만 처리가 남은 티켓을 표시한다. ‘전체 보기’를 누르면 **03-02 내게 할당된 티켓**으로 이동한다.
- 받은 요청 카드에는 본인에게 들어온 검토 요청을 표시한다. ‘전체 보기’를 누르면 **05-05 받은 검토 요청 목록**으로 이동하고, 요청을 누르면 해당 요청의 상세 패널을 연다.
- 내 실적에는 오늘과 전날의 처리 건수를 표시한다. 처리 건수 집계 기준은 추후 확정한다.
- 본문 오른쪽 위의 ‘화면 설정’을 누르면 **07-03 화면 설정**으로 이동한다.
- 표시할 카드가 없으면 화면 설정에서 카드를 다시 표시할 수 있도록 안내한다.


### 02-03 직원 의견 등록

- 업무 홈의 ‘직원 의견 등록’을 누르면 유형과 내용을 입력하는 화면을 연다. 등록 후 접수 번호를 표시한다.
- 실행 시안에서 개선 제안은 제목과 내용을 작성한다. 고충은 내용을 입력하지 않고 접수만 시연한다. 직원 의견 열람 권한이 있는 사용자는 업무 홈에서 ‘직원 의견 보기’를 열 수 있다.

## 03. 티켓 목록 (Task2)

[전체 티켓 열기](../src/pages/03-TicketListPage/03-TicketListPage.html) · [내게 할당된 티켓 열기](../src/pages/03-TicketListPage/03-TicketListPage.html#03-02)

### 03-01 티켓 목록

- 좌측 패널의 ‘티켓 목록’을 강조하고, 본문 상단에 ‘전체 티켓’과 ‘내게 할당된 티켓’ 탭을 표시한다. 전체 티켓 탭에는 열람 권한이 있는 티켓을 표시한다.
- 검색 대상은 제목, 고객 ID, 티켓 ID 중 하나를 선택한다. 검색어는 최대 50자까지 입력할 수 있다.
- 조회 결과 건수는 표 왼쪽 위에 표시한다. ‘페이지당 조회 건수’와 ‘필터 설정’은 표 오른쪽 위에 배치한다.
- 표에는 행 번호, 티켓번호, 제목, 카테고리, 담당자, 처리 상태, 감성, 최근 업데이트를 순서대로 표시한다. 행 번호는 현재 검색·필터 결과의 총건수부터 1씩 줄어든다. 페이지를 넘겨도 번호는 이어진다. 미할당 티켓의 담당자는 `-`로 표시한다.
- 표준화·저장이 완료된 티켓은 한 행씩 표시한다. 카테고리와 감성은 항목별로 ‘분석 중’ 또는 ‘분석 실패’를 표시한다. 감성 결과는 긍정·중립·부정·매우 부정을 색과 텍스트로 구분한다.
- 최근 업데이트에는 ‘1분 미만’, ‘5분 전’, ‘2일 전’처럼 경과 시간을 표시한다. 접수일자 오래된순 또는 최신순을 선택하면 그 아래에 접수 시각을 함께 표시한다. 접수 시각은 당일 `HH:mm`, 같은 해의 이전 날짜 `MM/DD`, 다른 해 `YYYY/MM/DD` 형식이다.
- ‘최근 업데이트’ 열 제목을 누를 때마다 기본 → 업데이트 최신순 → 업데이트 오래된순 → 접수일자 최신순 → 접수일자 오래된순 → 기본 순으로 전환한다. 기본은 접수일자 오래된순으로 정렬하고 업데이트 경과 시간만 표시한다.
- 페이지당 기본 조회 건수는 10건이다. 10·20·30·50건 중에서 선택할 수 있다. 전체 티켓 시안에는 예시 티켓 1,000건을 표시한다.
- 표 아래에 페이지 번호를 최대 10개씩 표시한다. 번호를 누르면 해당 페이지를 선택한다. `<`·`>`는 앞뒤 10개 묶음으로, `<<`·`>>`는 첫 페이지와 마지막 페이지로 이동한다. 첫 묶음에서는 왼쪽 화살표를, 마지막 묶음에서는 오른쪽 화살표를 숨긴다.

### 03-02 내게 할당된 티켓

- 로그인한 상담사에게 할당된 티켓을 표시한다.
- 전체 티켓과 같은 검색·필터·정렬 및 표 표시 규칙을 적용한다.

### 03-03 필터 적용

- ‘필터 설정’ 버튼을 누르면 처리 상태, 카테고리, 감성, 접수 기간을 한 창에서 설정한다.
- 처리 상태, 카테고리, 감성은 체크박스로 여러 항목을 선택할 수 있다.
- 접수 기간은 최근 1·3·7·30일 또는 ‘직접 지정’으로 선택한다.
- 필터가 적용되면 목록 위에 선택한 조건과 ‘초기화’를 표시한다.

### 03-04 검색 결과 없음

- 검색 또는 필터 조건에 맞는 티켓이 없으면 조회 결과를 0건으로 표시한다.
- 표 영역에 ‘검색 조건에 맞는 티켓이 없습니다.’와 ‘조건 초기화’ 버튼을 표시한다.

### 03-05 전체 카테고리 보기

- 필터 설정의 ‘전체 카테고리 보기’를 누르면 필터 창 오른쪽에 해당 고객사에 등록된 카테고리 목록을 표시한다.
- 카테고리는 체크박스로 여러 항목을 선택할 수 있다. ‘선택 완료’를 누르면 패널을 닫고 필터 설정으로 돌아간다.

### 03-06 접수 기간 직접 지정

- 접수 기간에서 ‘직접 지정’을 누르면 시작일과 종료일 달력을 나란히 표시한다.
- 두 날짜를 선택하고 ‘기간 적용’을 누르면 선택한 기간을 표시하고 필터 설정으로 돌아간다. 직접 지정 기간은 최대 365일이다.


## 04. 티켓 상세 (Task3_구현중)

[티켓 상세 시안 열기](../src/pages/04-TicketDetailPage/04-TicketDetailPage.html?ticket=1048)

### 04-01 티켓 상세

- 티켓 목록에서 행을 누르면 선택한 티켓의 상세 화면을 연다.
- 공통 상단 바와 좌측 패널을 표시하고, 좌측의 ‘티켓 목록’을 강조한다.
- 본문에 ‘티켓 목록’ 돌아가기 버튼과 ‘티켓 상세’ 제목을 배치하고, 중앙에 ‘준비중입니다.’를 표시한다.
- 목록에서 진입한 뒤 본문의 돌아가기 버튼을 누르면 이전 목록으로 돌아간다. 상세 화면을 직접 열었을 때는 지정된 목록 탭으로 돌아가며, 탭 지정이 없으면 전체 티켓 목록으로 이동한다.


## 05. 받은 요청 (Task6)

[받은 요청 시안 열기](../src/pages/05-InboxPage/05-InboxPage.html) · [받은 요청 없음 시안 열기](../src/pages/05-InboxPage/05-InboxPage.html?empty=1)

### 05-01 받은 요청 목록

- 좌측 ‘받은 요청’ 메뉴에서 수신함을 연다. ‘받은 이관’, ‘받은 검토 요청’, ‘받은 검토 답변’ 탭에 각각 미확인 건수를 표시한다.
- 받은 시각이 최신인 요청부터 표시한다. 열의 순서는 상태, 티켓, 이관 메시지 또는 검토 메모, 카테고리, 보낸 사람, 받은 시각이다. 상태는 미확인·확인으로 표시한다.
- 티켓 열에는 제목과 그 아래에 티켓번호를 표시한다. 검색·미확인 결과에도 같은 열 구성을 적용한다.
- 제목·티켓번호·보낸 사람으로 검색할 수 있다. ‘전체’와 ‘미확인’으로 확인 범위를 선택한다.

### 05-02 받은 이관 상세 · 05-03 받은 검토 요청 상세

- 요청 행을 누르면 오른쪽 상세 패널을 연다. 보낸 사람, 접수일자, 받은 시각, 상태, 티켓 처리 상태, 감성, 이관 메시지 또는 검토 메모 전문을 표시한다. 접수일자는 티켓 최초 접수 시각으로, `YYYY-MM-DD HH:mm` 형식을 사용한다. 감성은 티켓 처리 상태 아래에 색상 배지로 표시한다.
- 이관 요청에는 전달된 답변을, 검토 요청에는 참고 자료명을 표시한다. 자료가 있는 경우에만 해당 영역을 표시한다.
- 상세를 열면 요청의 미확인 표시가 해제되고 탭의 미확인 건수가 갱신된다. 티켓 처리 상태는 유지된다.
- 패널을 닫으면 보던 탭과 검색·필터 조건을 유지한다. ‘티켓 열기’를 누르면 **04-01 티켓 상세**를 연다.

### 05-04 받은 요청 없음

- 선택한 유형에 받은 요청이 없으면 ‘받은 요청이 없습니다.’를 표시한다.

### 05-05 받은 검토 요청 목록

- ‘받은 검토 요청’ 탭에서 검토 요청만 조회하며, 검토 메모를 한 줄로 미리 표시한다.

### 05-06 검색 결과 없음 · 05-09 검색 결과

- 검색 조건에 일치하는 요청을 표시하고, 일치하는 요청이 없으면 ‘검색 결과가 없습니다.’를 표시한다.
- ‘검색 초기화’를 누르면 검색어를 지우고 현재 탭과 확인 범위에 해당하는 요청을 표시한다.

### 05-07 미확인 이관 요청 · 05-08 미확인 검토 요청

- ‘미확인’을 선택하면 현재 탭의 미확인 요청만 표시한다. 상세를 열어 확인한 요청은 미확인 목록에서 제외한다.
- 미확인 요청이 없으면 ‘미확인 요청이 없습니다.’를 표시한다.


### 05-10 이관 이력

- 받은 이관 상세의 ‘이관 메시지’ 오른쪽에 ‘이관 이력’을 배치한다.
- 이관 이력을 열면 해당 티켓의 전체 이관 내역을 최신순으로 표시한다. 각 내역에는 이관 후 담당자, 이관 일시, 이관 메시지를 표시한다.
- ‘돌아가기’를 누르면 받은 이관 상세로 돌아간다.

### 05-11 검토 답변 작성 · 05-12 검토 답변 발송

- 검토 요청 상세에서 ‘회신하기’를 누르면 같은 패널에 답변 입력란을 연다. 받는 사람은 검토 요청자다.
- 공백만 입력한 답변은 보내기 버튼이 비활성화된다. 발송 실패 시 입력 내용을 유지하고 재시도할 수 있도록 안내한다.
- 요청마다 답변을 한 번 보낼 수 있다. 발송 후 원래 검토 요청 상세에 ‘보낸 답변’ 내용을 표시한다. 티켓 처리 상태는 유지한다.
- 실행 시안은 검토 답변을 브라우저에 저장한다.

### 05-13 받은 검토 답변 없음 · 05-14 받은 검토 답변

- 검토 답변은 요청자의 ‘받은 검토 답변’ 탭에 미확인으로 표시한다. 목록에는 상태, 티켓, 답변 한 줄, 카테고리, 보낸 사람, 받은 시각을 표시한다.
- 받은 답변이 없으면 ‘받은 검토 답변이 없습니다.’를 표시한다.

### 05-15 받은 검토 답변 상세

- 답변 행을 열면 상태를 확인으로 변경하고 탭의 미확인 건수를 줄인다.
- 상세 패널에서 보낸 사람, 받은 시각, 상태, 답변 내용을 확인한다. ‘원래 검토 요청 보기’와 ‘티켓 열기’를 제공한다.


## 06. 분석 대시보드 (Task7)

[조직 전체 조회 시안](../src/pages/06-AnalyticsDashboardPage/06-AnalyticsDashboardPage.html?preview=administrator) · [담당 팀 조회 시안](../src/pages/06-AnalyticsDashboardPage/06-AnalyticsDashboardPage.html?preview=team-lead) · [요약만 조회하는 시안](../src/pages/06-AnalyticsDashboardPage/06-AnalyticsDashboardPage.html?preview=overview-only) · [접근 권한 없음 시안](../src/pages/06-AnalyticsDashboardPage/06-AnalyticsDashboardPage.html)

### 06-01 조직·팀 실적

- 관리자는 공통 분석 대시보드에서 허용된 조직·팀의 실적을 조회한다. 조직 전체 조회 권한이 있으면 조직 전체를, 팀 범위 권한이 있으면 담당 팀을 기본으로 표시한다.
- 조회 기간을 선택한다. 조직 범위 선택에는 권한이 있는 항목만 표시한다. 대시보드 안에서 탭을 바꿔도 기간과 범위는 유지한다.
- 신규 접수, 처리 완료, 24시간 이상 미처리, 부정·매우 부정 문의 비율, 고객 만족도(CSAT)를 상단에 표시한다. 기간 지표의 증감은 선택 기간 바로 앞의 같은 길이 기간을 기준으로 비교한다.
- 현재 미처리와 24시간 이상 미처리는 조회 시점 기준이다. 도넛은 미할당, 담당자 배정, 보류의 건수 및 비율을 표시한다. 24시간은 시안의 장기 미처리 기준이다.
- 부정·매우 부정 문의 비율은 감성 분석 완료 건수로 나눈다. 분석 중·실패 건수를 함께 표시한다. CSAT는 5점 설문에서 4·5점으로 응답한 건수의 비율이며, 총 응답 수와 만족 응답 수를 함께 표시한다.
- 신규 접수·처리 완료 추이를 꺾은선 차트로 표시하고, 접수 건수가 가장 많이 증가한 카테고리를 최대 3개 보여준다. 고객 대기 시간에는 접수부터 첫 고객 답변까지와 접수부터 처리 완료까지의 중앙값을 표시한다.

### 06-02 상담사별 실적

- 개인 실적 조회 권한이 있는 사용자에게만 ‘상담사별 실적’ 탭을 표시한다.
- 상담사, 소속 팀, 선택 기간 내 배정·처리 완료, 현재 미처리, 첫 답변 중앙값을 표시한다. 처리 완료 건수는 완료를 기록한 상담사에게 집계한다.
- 현재 미처리는 조회 시점 기준이며 다음 세 열로 표시한다.
  - 할당 티켓은 현재 해당 상담사에게 일반 배정되어 있으며 처리가 끝나지 않은 티켓이다.
  - 이관은 현재 해당 상담사가 이관받아 담당하고 있으며 처리가 끝나지 않은 티켓이다. 같은 티켓은 할당 티켓과 이관 중 한 열에만 집계한다.
  - 검토 요청은 해당 상담사가 받은 요청 중 아직 회신하지 않은 건이다. 요청 열람 여부와 관계없이 회신할 때까지 집계하며, 티켓 건수와 별도로 본다.
- 첫 답변 중앙값은 선택 기간에 해당 상담사가 티켓의 첫 고객 답변을 보낸 건을 대상으로, 최초 접수부터 고객에게 첫 답변을 발송하기까지 걸린 시간의 중앙값이다. 내부 메모와 검토 회신은 집계에서 제외한다.
- ‘조직·팀 실적’과 기간 및 조직 범위 선택을 공유한다. 상담사 이름을 누르면 **06-04 상담사 상세**로 이동한다.

### 06-03 접근 권한 없음

- 모든 사용자에게 좌측 ‘분석 대시보드’ 메뉴를 표시한다. 조회 권한이 없는 사용자가 열면 본문에 ‘접근 권한이 필요합니다.’를 표시한다.
- 실행 시안에서는 안내 아래의 ‘임시 접근’을 누르면 관리자 계정 시안으로 전환한다. 사원 계정을 지정해 볼 때는 해당 계정의 역할과 개인 예외를 적용한다.

### 06-04 상담사 상세

- 개인 실적 조회 권한이 있는 사용자가 허용된 범위에서 상담사 상세를 열 수 있다. 상담사 이름, 소속 팀, 목록에서 선택한 기간을 표시한다.
- 지표 카드에는 기간 내 배정·처리 완료, 현재 미처리 티켓, 첫 답변 중앙값, 미회신 검토 요청을 표시한다.
- 배정·처리 완료 추이는 일자별 꺾은선 차트로 표시한다. 현재 미처리 도넛에는 할당 티켓과 이관 티켓을 집계한다. 미회신 검토 요청은 별도 지표 카드로 표시한다.
- ‘‹ 상담사별 실적’을 누르면 이전 목록으로 돌아간다. 기간과 조직 범위는 유지한다.

## 07. 설정

[설정 시안 열기](../src/pages/design-preview/07-SettingsPage/07-SettingsPage.html)

### 07-01 설정 홈

- 개인 설정에는 신속답변과 화면 설정을 표시한다. 업무 관리에는 메신저 연동과 자동 배정을, 인사 관리에는 사원 관리와 권한 관리를 표시한다.
- 사용자는 접근 권한이 있는 설정을 열 수 있다. 권한이 없는 설정 주소에 들어가면 권한 안내를 표시한다.

### 07-02 신속답변

- 내 신속답변은 본인이 조회·등록·편집·삭제한다. 팀 신속답변은 해당 팀원이 조회·사용할 수 있다. 팀 신속답변의 등록·편집·삭제에는 편집 권한이 필요하다.
- 등록할 때 이름, 카테고리, 답변 내용을 입력한다. 팀 신속답변은 공유할 소속 팀을 선택한다.
- 이름 검색, 카테고리, 소속 팀, 즐겨찾기로 목록을 좁힐 수 있다. 답변을 선택해 본문을 미리 보고, 즐겨찾기는 사용자별로 저장한다.

### 07-03 화면 설정

- 업무 홈 카드는 항목별로 표시 여부를 선택하고, 드래그하거나 위·아래 버튼으로 순서를 바꾼다. 기본 배치 복원 시 세 카드를 표시하고 기본 순서로 되돌린다.
- 좌측 패널에 표시할 메뉴를 선택한다. 업무 홈에서 진입한 경우 저장 후 업무 홈으로 돌아가며, 개인 설정에서 진입한 경우 개인 설정으로 돌아간다. 취소하면 이전 설정을 유지한다.

### 07-04 사원 관리

- 사원 목록에서 이름·회사 이메일로 검색하고, 소속 팀과 계정 상태로 필터링한다. 계정 상태는 설정 대기, 활성, 비활성으로 표시한다.
- 계정 발급 시 이름, 회사 이메일, 소속 팀, 역할을 입력한다. 발급된 계정은 ‘설정 대기’로 표시한다. 등록된 이메일을 입력하면 안내와 ‘기존 사원 보기’를 표시한다.
- 사원 상세에서 기본 정보, 업무 권한, 변경 이력을 확인한다. 소속·권한을 변경할 때 새 역할의 기본 권한, 현재 권한, 변경 후 권한을 비교한다. 실제 적용값에 역할 기본값 또는 개인 예외를 함께 표시한다. 개인 허용·개인 제한·역할 기본값 중 하나를 선택한다. 소속 팀 변경 시 팀 신속답변 조회 범위와 인수인계 대상인 미처리 티켓·미회신 검토 요청 건수를 표시한다.
- 비밀번호 초기화 시 대상 계정을 확인한다. 실행 시안은 초기화 요청 일시와 실행자를 변경 이력에 남긴다.
- 계정 비활성화 전에 미처리 티켓·미회신 검토 요청 건수를 확인한다. 남은 업무가 있으면 ‘인수인계 필요’를 표시하고 비활성화를 제한한다.
- 변경 이력에 일시, 변경한 사람, 변경 항목, 변경 전·후 값을 표시한다.

### 07-05 메신저 연동

- Discord 연동의 사용 여부와 수신 대상을 설정한다.

### 07-06 자동 배정

- 자동 배정을 켜면 표준화와 저장을 마친 신규 미배정 티켓 중 설정한 카테고리와 채널이 일치하는 티켓을 대상으로 삼는다. 채널을 선택하지 않으면 전체 채널을 대상으로 한다. 카테고리 분석 중에도 목록에서 티켓을 볼 수 있고, 배정은 분류 결과가 나온 뒤 판단한다.
- 고객사 시간대 기준으로 운영 요일, 시작·종료 시각과 공휴일 제외 여부를 설정한다. 종료 시각은 시작 시각보다 늦어야 한다.
- 한 번에 배정할 건수와 담당자당 동시 처리 한도를 따로 정한다. **1건 처리 시 1건 보충**은 한 건을 처리할 때마다 한 건을 추가한다. **배정분을 모두 처리한 뒤 일괄 배정**은 기존 배정분을 마친 뒤 설정한 건수만큼 배정한다.
- 카테고리 담당 팀과 운영자가 지정한 포함 팀·담당자를 기준으로 배정 대상을 좁힌다. 팀 또는 담당자 제외 조건이 우선한다. 계정이 활성이고 상담 가능 상태이며 티켓·채팅 중 하나 이상의 상담 권한을 가진 사원만 배정 후보가 된다.
- 오래 접수된 티켓부터 검토한다. 가능한 담당자 중 현재 처리 건수가 적고 마지막 배정 시각이 오래된 사람을 우선한다. 후보가 없거나 처리 한도에 도달하면 미배정으로 유지한다. 운영 시간에 들어오거나 배정 가능 상태가 바뀌면 다시 확인한다.
- 실행 시안은 브라우저에 설정을 저장하고, 예시 요일·시각·배정 시점에 따른 담당자 및 대기 사유를 보여준다. 실제 배정 실행과 저장, 재시도, 이력 기록은 서버 연동 단계에서 검증한다.

### 07-07 권한 관리

[권한 관리 열기](../src/pages/design-preview/07-SettingsPage/07-SettingsPage.html?view=permissions)

- **07-07-01 권한 관리**에서 상담사와 팀 리더의 기본 권한을 비교한다. 티켓 조회·처리·배정·이관은 두 역할에 공통으로 제공한다. 검토 요청을 받은 직원은 해당 티켓의 문의 본문, 첨부파일과 이전 대화를 열람할 수 있다.
- **07-07-02 역할 권한 편집**에서 팀 신속답변 편집, 분석 대시보드 열람, 직원 의견(VoE) 열람을 역할별로 설정한다. 초기 기본값은 팀 리더에게 세 권한을 모두 허용한다. 팀 신속답변의 편집 범위는 소속 팀이다. 대시보드에서 팀 리더는 소속 팀의 실적을 조회한다. 직원 의견 열람 권한은 목록·상세 열람에 적용하며, 고충의 공개 범위와 처리 권한은 별도로 적용한다.
- **07-07-03 권한 변경 확인**에서 변경 전후와 기본값이 바뀌는 기존 사원 수를 확인하고 저장한다. 저장한 기본값은 해당 역할의 기존·신규 사원에게 적용한다. 사원 상세의 개인 예외는 유지하고, 예외를 해제하면 최신 역할 기본값을 적용한다.
- 신속답변, 대시보드, 직원 의견 화면을 다시 열면 저장된 역할 기본값과 개인 예외를 적용한다. 권한이 없는 사용자는 대시보드나 직원 의견 주소를 직접 열어도 접근 안내를 본다. 신속답변의 팀 조회·사용은 소속 팀 기준을 적용한다.
- 실행 시안에서는 관리자 설정으로 권한을 변경한 뒤, 같은 로컬 서버 주소에서 [팀 리더 업무 홈](../src/pages/design-preview/02-WorkHomePage/02-WorkHomePage.html?as=hn) 또는 [상담사 업무 홈](../src/pages/design-preview/02-WorkHomePage/02-WorkHomePage.html?as=sy)으로 적용 결과를 확인한다. 권한과 시연 계정 정보는 해당 브라우저에 저장한다.

### 확정 필요 사항

- **상담 상태 변경 권한** — 직원 본인과 팀 관리자 중 누가 상담 가능 상태를 변경할 수 있는지와 변경 범위.
- **사원 계정 및 인수인계** — 임시 비밀번호 전달 경로, 계정 활성 전환 시점, 소속 변경·비활성화 시 남은 업무를 넘기는 절차.
- **자동 배정 집계** — 티켓 재오픈, 보류, 수동 배정이 1건 보충과 담당자 동시 처리 한도 계산에 미치는 영향.
